# Display icons

Served by the service at `/v1/icon/<name>` (wire format in `WIDGET-PROTOCOL.md`), generated by
`scripts/build_icons.py` into `smalltv_monitor/display/icon_data.py`. Source SVGs are kept in `icons/svg/`.

| Name | Source | Licence |
|---|---|---|
| `claude`, `codex` (OpenAI mark), `cursor`, `slack` | [Simple Icons](https://simpleicons.org) 15.22.0 | CC0-1.0 (icon data); the marks are trademarks of their owners |
| `cpu`, `mem` (memory-stick), `disk` (hard-drive), `gpu` | [Lucide](https://lucide.dev) 0.544.0 | ISC |
| `slack-rest`, `slack-unread`, `slack-mention` | Slack desktop app's own tray images (`slack-taskbar-{rest,unread,highlight}.ico`, native 16×16 frame), read from the local install at build time | © Slack Technologies, LLC, a Salesforce company. Slack, its logo and artwork are its trademarks and copyright; included only to show Slack's status on this display, not covered by this repository's licence |

To add an icon: add an entry to `ICONS` in `scripts/build_icons.py`, run it, and reference the name
from `display/dashboard.py`. No firmware change is needed: the device fetches unknown icons by name
and caches them by content hash.
